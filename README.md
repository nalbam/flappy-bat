# Flappy Bat / 박쥐의 야간비행

Three.js와 순수 JavaScript로 만든, 빌드 과정이 필요 없는 GitHub Pages용 3D 플래피 게임입니다. 모든 동굴, 바위, 박쥐, 파티클은 런타임에 절차적으로 생성됩니다.

## 실행

`docs/main.js`는 `docs/input.mjs`, `docs/view.mjs`, `docs/game-rules.mjs`, `docs/game-core.mjs`를 불러오는 native ES module(`<script type="module">`)입니다. 브라우저는 `file://`로 연 페이지에서 module을 불러오지 않으므로 `docs/index.html`을 직접 열면 게임이 시작되지 않습니다. 반드시 HTTP 서버로 엽니다.

1. 저장소 루트에서 정적 서버를 실행합니다.

   ```bash
   python3 -m http.server 8000
   ```

2. 브라우저에서 `http://localhost:8000/docs/`를 엽니다.

설치나 빌드는 필요 없습니다. Three.js는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

- 박쥐는 화면 왼쪽에서 오른쪽으로 날아가는 횡스크롤로 진행하며, 동굴과 기둥이 오른쪽에서 왼쪽으로 흘러옵니다. 카메라는 비행 평면을 옆에서 기울이지 않고 고정해서 비추므로, 기둥 틈의 높이가 비행 중에 바뀌어 보이지 않습니다.
- 날갯짓: `Space` / `ArrowUp` / 클릭 / 탭. 키를 한 번 누를 때마다 한 번만 날갯짓하며, 누르고 있어도 반복되지 않습니다.
- 시작: 시작 화면에서 날갯짓 입력을 하거나 `날아오르기` 버튼을 누릅니다. 버튼에 포커스한 상태에서는 `Enter`도 동작합니다. 시작 입력도 일반 날갯짓과 같은 상승 속도를 한 번 줍니다.
- 빠른 재시작: 충돌하면 결과 카드에 통과한 기둥 수와 최고 기록이 표시됩니다. 새로 `Space`·`ArrowUp`을 누르거나, 화면을 클릭·탭하거나, `다시 시작` 버튼을 누르면 한 번에 새 비행을 시작합니다. 충돌할 때 누르고 있던 키로는 재시작하지 않으므로 키를 뗐다가 다시 누릅니다.
- 현재 점수는 비행마다 초기화되며, 최고 점수만 브라우저 `localStorage`에 저장됩니다.
- 운영체제에서 동작 줄이기(`prefers-reduced-motion`)를 켜면 충돌 시 화면 흔들림을 끕니다.

## 게임 규칙과 시간 처리

| 파일 | 역할 |
|---|---|
| `docs/game-rules.mjs` | 고정 tick, 중력, 날갯짓 속도, 속도 증가·상한, 박쥐 몸통 크기, 동굴 경계, 수직 적분 |
| `docs/game-core.mjs` | `ready`/`running`/`over` 상태, 박쥐 위치·속도, 점수, 장애물 9개, 프레임 시간 처리 |
| `docs/main.js` | 모델 결과를 Three.js 장면과 HUD에 반영하고 효과를 실행하는 어댑터 |

- 시뮬레이션은 1/120초 고정 tick으로 진행합니다. 같은 tick에 같은 입력을 주면 화면 주사율(30·60·144Hz 등)과 관계없이 결과가 같습니다.
- 한 프레임에서 따라잡는 시간은 최대 0.1초(12 tick)입니다. 그보다 긴 멈춤은 초과분을 버리므로, 박쥐가 순간 이동하지 않고 게임이 그만큼 느려집니다.
- 탭이 숨겨진 동안의 시간은 시뮬레이션하지 않습니다. 탭이 다시 보이면 숨기기 직전 상태에서 이어집니다. 별도의 일시정지 화면은 없습니다.
- `ready`와 `over` 상태에서는 게임 모델(박쥐 위치·속도, 장애물, 점수)이 진행하지 않습니다. 충돌 뒤 박쥐가 떨어지는 모습은 화면 효과입니다.
- 시작 입력(첫 시작과 재시작)은 프레임 시계를 다시 시작합니다. 시작 직후 첫 프레임은 0초로 처리하므로 `ready`·`over`에서 보낸 시간은 새 비행에 들어가지 않습니다.
- 박쥐 몸통 전체가 기둥의 뒤쪽 면을 벗어나면 기둥마다 한 번 득점합니다. 충돌한 tick에는 점수를 주지 않습니다.

## 테스트

모든 테스트는 DOM·WebGL 없이 Node.js 내장 `node:test`로 실행합니다. Node.js 20 이상이 필요하며 패키지 설치나 앱 빌드는 없습니다. 저장소 루트에서 실행합니다.

```bash
node --test
```

- `tests/game-core.test.mjs`: 30·60·144Hz와 지연 프레임에서 같은 tick 입력의 결과가 같은지, catch-up 한도, 탭 복귀, 시작 충격, `ready`·`over`에서 정지, 기둥마다 한 번 득점과 충돌 tick 무득점, 재시작 초기화
- `tests/input.test.mjs`: 키 반복 무시, `keyup`·`blur`·탭 비활성 후 재입력, 버튼 `click`과 키 입력의 중복 방지, 충돌 중 누른 키로 재시작하지 않음
- `tests/view.test.mjs`: 화면 비율마다 카메라 시야가 박쥐 뒤쪽 여유, 박쥐 앞 9.5 단위(다가오는 기둥을 판단하는 구간), 비행 높이 범위를 모두 포함하고 박쥐가 화면 왼쪽에 있는지 확인

GitHub Actions의 `.github/workflows/test.yml`도 `main` push와 pull request에서 Node.js 22로 같은 명령을 실행합니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main`, Folder를 `/docs`로 선택하면 됩니다. 저장 후 Pages가 제공하는 주소에서 바로 플레이할 수 있습니다.

외부 에셋은 사용하지 않으며, Three.js만 CDN에서 불러옵니다.
